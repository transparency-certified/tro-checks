## Diagnostics for Each Unmet Expectation
### Unmet expectation: base-host-ownable
Expectation details: Where an @context declares a non-null @base, its host is a domain name the minter could hold: a dotted name whose labels a registrar would accept, and not one of the names reserved so that nobody can ever hold them. A base under a reserved name cannot be under the control of the TRO's minter, which is a fact the RFCs record rather than a rule TRACE makes. The reserved list is RFC 2606 and 6761's .test, .example, .invalid and .localhost with example.com, example.net and example.org, RFC 6762's .local, RFC 8375's home.arpa, RFC 9476's .alt, and .internal, which ICANN reserved by board resolution rather than by RFC. The patterns read lowercase names; an uppercase spelling is refused by base-host-lowercase.
| Found | Where | Expectation not met because |
| --- | --- | --- |
| `"https://tro.example.org/tro/1/"` | `/@context/@base` | an @base host is not under example.com, example.net or example.org, which are reserved for documentation |

## Diagnostics for Each Unmet Expectation
### Unmet expectation: base-host-ownable
Expectation details: Where an @context declares a non-null @base, its host is a domain name the minter could hold: a dotted name whose labels a registrar would accept, and not one of the names reserved so that nobody can ever hold them. A base under a reserved name cannot be under the control of the TRO's minter, which is a fact the RFCs record rather than a rule TRACE makes. The reserved list is RFC 2606 and 6761's .test, .example, .invalid and .localhost with example.com, example.net and example.org, RFC 6762's .local, RFC 8375's home.arpa, RFC 9476's .alt, and .internal, which ICANN reserved by board resolution rather than by RFC. The patterns read lowercase names; an uppercase spelling is refused by base-host-lowercase.
